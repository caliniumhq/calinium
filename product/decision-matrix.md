# Purpose

This document defines who makes every important decision during the creation of a Shopify storefront.

The objective is simple.

The merchant should make business decisions.

Calinium should make design and technical decisions.

Whenever possible:

Calinium recommends.

The merchant approves.

---

# Core Rule

Before asking a question, ask:

Can Calinium determine this confidently?

If yes:

Do not ask.

Recommend instead.

# Golden Rule

Merchants should never need to answer questions that only designers, developers, or Shopify experts understand.

If Calinium can make a professional recommendation with confidence, it should.

The merchant's responsibility is to explain the business.

Calinium's responsibility is to transform that understanding into an exceptional storefront.

---

# Success Test

Whenever a new feature is proposed, ask:

Does this require the merchant to make another decision?

If yes...

Can Calinium make that decision instead?

If the answer is yes...

The feature should be redesigned.

---

# Final Principle

The merchant should leave Calinium feeling:

"I never designed a website.

I simply explained my business."

Everything else was Calinium's job.
