# Calinium Corner Radius System

## Purpose

The Calinium Corner Radius System defines how shape is expressed throughout every Calinium experience.

Corner radius is more than a visual style.

It influences perception, trust, usability, and the emotional character of an interface.

Consistent corner radii help create products that feel calm, refined, modern, and predictable.

Every component should derive its shape from this system rather than using arbitrary values.

---

# Design Principles

## Principle 01 — Shape Communicates Personality

Corners influence how users perceive an interface.

Sharp corners communicate precision, structure, and technical confidence.

Rounded corners communicate warmth, approachability, and comfort.

Calinium balances both to create interfaces that feel premium, trustworthy, and timeless.

---

## Principle 02 — Consistency Creates Recognition

Customers should unconsciously recognize a visual language across every page.

Components that share similar purposes should share similar corner radii.

Consistency strengthens brand identity.

---

## Principle 03 — Radius Supports Hierarchy

Shape contributes to hierarchy.

Primary interactive components may use more expressive radii.

Structural elements should remain subtle.

The interface should never feel playful unless intentionally designed to do so.

---

## Principle 04 — Restraint Over Decoration

Large radii should never become decoration.

Rounded corners exist to improve perception and usability—not to create visual trends.

Calinium avoids exaggerated pill shapes unless they improve interaction.

---

## Principle 05 — One System, Many Components

Every radius originates from shared design tokens.

Components must never define custom corner values.

This ensures consistency across every preset and generated storefront.

---

# UX Foundations

## Gestalt Principle — Similarity

Elements with similar corner radii are naturally perceived as belonging to the same system.

Consistent shape language improves recognition and reduces cognitive effort.

---

## Jakob's Law

Users expect familiar interface conventions.

Buttons, cards, inputs, dialogs, and controls should use shapes consistent with modern ecommerce expectations.

Avoid unconventional geometry that slows recognition.

---

## Aesthetic-Usability Effect

Users often perceive attractive interfaces as easier to use.

Consistent radii contribute to visual harmony and increase perceived quality.

Beauty should reinforce usability—not replace it.

---

## Fitts's Law

Interactive controls should provide comfortable touch targets.

Rounded corners can improve perceived touchability, but usability depends primarily on target size and spacing.

Radius should never reduce the effective interactive area.

---

## Cognitive Load

Shape should help users recognize component types instantly.

Customers should never need to consciously interpret whether an element is interactive.

Consistency reduces mental effort.

---

# Radius Tokens

Every component must use semantic radius tokens.

Avoid arbitrary values.

## None

Used only when square edges are intentionally required.

Examples:

- Image grids
- Editorial layouts
- Technical previews

---

## Small

Minimal softening.

Suitable for:

- Inputs
- Badges
- Small controls

---

## Medium

Default component radius.

Used for:

- Buttons
- Cards
- Product tiles
- Dropdowns

This should become the most commonly used radius throughout Calinium.

---

## Large

Used for:

- Feature cards
- Promotional banners
- Collection highlights
- Editorial containers

Should remain uncommon.

---

## Extra Large

Reserved for hero content and major promotional layouts.

Should be used sparingly.

---

## Full

Fully rounded shapes.

Examples:

- Circular avatars
- Status indicators
- Icon buttons
- Chips

Should never become the default interface style.

---

# Component Rules

## Buttons

Primary buttons should use the default system radius.

Avoid excessively rounded buttons unless required by a preset.

---

## Cards

Cards should feel structured.

Radius should soften the experience without becoming visually dominant.

---

## Product Cards

Product imagery should remain the focal point.

Corner radius should complement—not compete with—the photography.

---

## Inputs

Inputs should communicate stability and precision.

Radius should remain subtle and familiar.

---

## Dialogs

Dialogs may use slightly larger radii than surrounding components to communicate elevation.

---

## Images

Images should inherit the radius appropriate for their container.

Do not mix multiple radius styles within the same visual group.

---

## Badges

Badges should remain compact.

Avoid large pill shapes unless their purpose requires strong visual emphasis.

---

# Shape Hierarchy

Radius contributes to hierarchy.

Recommended order:

- Structural surfaces
- Interactive controls
- Elevated containers
- Promotional content
- Decorative elements

Visual importance should increase gradually.

---

# Preset Personality

Each Calinium preset may define its own radius values while preserving semantic relationships.

Examples:

Editorial

- Minimal radius
- Structured appearance

Luxury

- Subtle radius
- Calm refinement

Technology

- Sharper geometry
- Precision

Furniture

- Softer curves
- Warm appearance

Beauty

- Slightly more rounded
- Elegant presentation

The semantic system remains identical.

Only token values change.

---

# Accessibility

Radius must never reduce usability.

Interactive controls should remain easy to identify and comfortably clickable.

Shape alone should never communicate status or meaning.

Visual states must also rely on:

- Color
- Contrast
- Labels
- Icons
- Motion (when appropriate)

---

# Merchant Customization

Merchants should customize overall shape language rather than individual component radii.

Suggested presets include:

- Sharp
- Subtle
- Balanced
- Soft

All components update automatically while preserving proportional relationships.

---

# AI Guidelines

When generating storefronts, AI should:

- Preserve consistent radius usage.
- Match shape language to the selected preset.
- Avoid mixing unrelated radius values.
- Reinforce visual hierarchy through subtle variation.
- Prioritize timeless design over temporary trends.

Radius should support the brand personality without becoming the visual focus.

---

# Future Compatibility

Before introducing a new radius token, ask:

- Can an existing token be reused?
- Does it improve consistency?
- Does it strengthen hierarchy?
- Does it reduce cognitive load?
- Does it align with the chosen preset?

If not, reuse the existing token.

The Calinium Corner Radius System values consistency, restraint, and craftsmanship over stylistic novelty.

Corners should feel intentional—not noticeable.
