# Calinium Spacing System

## Purpose

The Calinium Spacing System defines the rhythm, structure, and breathing room used throughout every Calinium experience.

Spacing is not empty space.

It is a design tool that creates hierarchy, improves readability, reduces cognitive load, and guides attention.

Consistent spacing makes interfaces feel calm, predictable, and premium.

Every component, section, and layout should derive its spacing from this system.

---

# Design Principles

## Principle 01 — Space Creates Focus

Whitespace is not wasted space.

It directs attention toward what matters most.

The more important an element is, the more space it deserves.

### Implications

- Use whitespace to emphasize products.
- Separate unrelated information.
- Avoid dense layouts.
- Allow content to breathe.

---

## Principle 02 — Rhythm Creates Harmony

Interfaces should feel visually balanced.

Spacing should follow a predictable rhythm rather than arbitrary values.

Consistency creates familiarity.

### Implications

- Reuse spacing tokens.
- Avoid one-off spacing values.
- Maintain proportional relationships.

---

## Principle 03 — Proximity Communicates Relationships

Objects placed close together are perceived as related.

Objects separated by larger spaces are perceived as independent.

Spacing should communicate structure before borders or color.

### Implications

- Keep related content together.
- Separate different sections clearly.
- Use spacing before introducing dividers.

---

## Principle 04 — Less Visual Noise

Dense interfaces increase mental effort.

Generous spacing reduces stress and improves comprehension.

Luxury experiences prioritize clarity over density.

---

## Principle 05 — Consistency Builds Trust

Customers should never consciously notice spacing.

It should feel natural throughout the entire experience.

Every page should follow the same spatial language.

---

# UX Foundations

## Gestalt Principle — Proximity

Elements positioned close together are perceived as belonging together.

### Application

- Product title stays close to price.
- Labels stay close to inputs.
- Buttons stay close to related actions.
- Feature icons remain grouped with descriptions.

---

## Miller's Law

People process information in manageable groups.

### Application

- Break content into logical sections.
- Separate unrelated information.
- Avoid overwhelming layouts.

Spacing helps chunk information naturally.

---

## Hick's Law

More visual information increases decision time.

### Application

- Increase whitespace around primary actions.
- Remove unnecessary visual clutter.
- Simplify scanning.

---

## Law of Prägnanz

People naturally perceive the simplest structure.

### Application

Clean spacing creates cleaner mental models.

Interfaces should feel organized at first glance.

---

## Cognitive Load

Whitespace reduces mental effort.

Customers should instantly recognize:

- what belongs together
- what deserves attention
- where one section ends
- where another begins

Spacing should answer those questions without requiring thought.

# Layout Spacing

Every page should establish hierarchy using spacing before introducing visual decoration.

Order of separation:

1. Micro spacing
2. Component spacing
3. Section spacing
4. Page spacing

Each level should feel visually distinct.

---

# Component Rules

## Buttons

Internal spacing should prioritize comfortable touch interaction.

Buttons should never feel cramped.

---

## Cards

Internal spacing should separate:

- image
- title
- description
- actions

Cards should feel balanced.

---

## Product Pages

Group:

- title
- price
- variants
- purchase actions

Separate:

- descriptions
- recommendations
- related content

Customers should understand page structure without reading.

---

## Forms

Labels remain visually connected to inputs.

Inputs remain grouped logically.

Related fields stay together.

Unrelated groups receive larger spacing.

---

## Navigation

Navigation should remain visually calm.

Avoid excessive spacing that breaks scanning.

Avoid compressed spacing that increases accidental interactions.

---

# Responsive Spacing

Spacing should adapt proportionally across screen sizes.

Smaller screens require tighter layouts while preserving hierarchy.

The relationship between spacing levels should remain consistent regardless of device.

---

# Accessibility

Spacing improves accessibility.

Adequate spacing reduces accidental taps and improves readability.

Interactive elements should have sufficient separation for touch interaction.

Whitespace should improve—not reduce—clarity.

---

# Merchant Customization

Merchants should select overall spacing density rather than editing individual margins.

Suggested density presets:

- Compact
- Comfortable
- Spacious

Components automatically adjust while preserving proportional relationships.

---

# AI Guidelines

When generating themes, AI should:

- Preserve consistent spacing rhythm.
- Increase whitespace around premium content.
- Reduce unnecessary density.
- Group related information.
- Separate unrelated information.
- Maintain visual balance.

Spacing should never appear random.

Every gap should communicate structure.

---

# Future Compatibility

New spacing tokens require strong justification.

Before introducing a new spacing value, ask:

- Can an existing token be reused?
- Does it improve consistency?
- Does it reduce cognitive load?
- Does it reinforce hierarchy?
- Does it improve readability?

If not, use an existing spacing token.

The Calinium Spacing System prioritizes rhythm, consistency, and clarity over flexibility.
