# Calinium Grid System

## Purpose

The Calinium Grid System defines the structural framework that organizes every page, section, and component across Calinium.

The grid is not simply a layout tool.

It establishes rhythm, balance, alignment, hierarchy, and consistency throughout the entire experience.

A well-designed grid should never be noticed.

Customers should simply feel that every interface is organized, predictable, and effortless to understand.

---

# Design Principles

## Principle 01 — Structure Creates Clarity

A consistent structure reduces cognitive effort.

Customers should immediately understand where content belongs without consciously interpreting the layout.

The grid should make interfaces feel calm and predictable.

---

## Principle 02 — Alignment Builds Trust

Misaligned elements create visual tension.

Consistent alignment communicates craftsmanship, precision, and professionalism.

Every component should align to a shared grid whenever possible.

---

## Principle 03 — Rhythm Creates Harmony

Consistent spacing between columns, rows, and sections creates visual rhythm.

The interface should feel balanced rather than mathematically rigid.

The goal is harmony—not symmetry.

---

## Principle 04 — Content Determines Layout

Layouts should adapt to content.

Content should never be forced into a grid that reduces readability or usability.

The grid serves the content.

The content never serves the grid.

---

## Principle 05 — Flexibility Without Chaos

The grid provides structure while allowing variation.

Every page should feel unique without feeling inconsistent.

---

# UX Foundations

## Gestalt Principle — Alignment

Users naturally perceive aligned elements as organized and related.

Consistent alignment reduces visual complexity and improves scanning.

---

## Gestalt Principle — Proximity

Related content should remain within shared grid regions.

The grid should reinforce logical grouping.

---

## Miller's Law

Breaking content into predictable regions reduces working memory requirements.

Well-defined columns help users process information more efficiently.

---

## Hick's Law

Organized layouts reduce perceived complexity.

Customers should find information quickly without evaluating unnecessary visual noise.

---

## Jakob's Law

Users expect familiar ecommerce layouts.

Important content should appear where customers naturally expect to find it.

Innovation should improve usability—not reduce familiarity.

---

## Cognitive Load

A predictable grid reduces mental effort.

Customers should understand page structure within seconds.

Good alignment eliminates unnecessary thinking.

---

# Grid Philosophy

The grid exists to create order—not restriction.

Every layout should feel intentional.

Every section should align with surrounding content.

Every page should reinforce the visual language established throughout the system.

---

# Containers

Containers define readable content width.

They should prevent lines of text and layouts from becoming excessively wide.

Container widths should prioritize readability over maximizing screen usage.

---

# Columns

Columns organize horizontal structure.

The number of visible columns may vary between layouts while preserving consistent spacing and alignment.

Columns should adapt responsively across screen sizes.

---

# Gutters

Gutters separate columns.

They improve readability by preventing visual collisions.

Gutters should remain consistent throughout the system.

---

# Vertical Rhythm

Horizontal consistency is only half of the system.

Vertical spacing creates reading rhythm.

Every section should contribute to an overall sense of flow throughout the page.

---

# Responsive Grid

The grid adapts continuously across devices.

Rather than shrinking desktop layouts, content should reorganize naturally for each screen size.

Every breakpoint should preserve hierarchy and readability.

---

# Component Rules

## Hero Sections

Hero layouts should prioritize imagery while maintaining readable content alignment.

Text should align consistently with surrounding page content.

---

## Product Grid

Products should align consistently regardless of image proportions.

Scanning should remain effortless.

Comparison should feel natural.

---

## Product Pages

Product information should follow predictable vertical alignment.

Primary purchase actions should remain visually prominent.

---

## Collection Pages

Filters, sorting, and product grids should share a common structural rhythm.

Customers should understand the page without searching for controls.

---

## Forms

Labels, fields, validation, and actions should align consistently.

Related inputs remain visually grouped.

---

## Footer

Footer columns should communicate hierarchy through alignment rather than decoration.

Readable line lengths.

Logical reading order.

Consistent focus movement.

Responsive layouts.

Adequate spacing between interactive elements.

Accessibility should emerge naturally from good structure.

Section width

---

# AI Guidelines

When generating storefronts, AI should:

- Preserve consistent alignment.
- Prioritize readable content widths.
- Maintain balanced spacing.
- Reduce visual clutter.
- Keep primary actions within natural scanning paths.
- Avoid unnecessary asymmetry.

The grid should disappear behind the content.

Products—not layout—should attract attention.

---

# Future Compatibility

Before introducing a new layout pattern, ask:

- Does it align with the existing grid?
- Does it improve readability?
- Does it reduce cognitive load?
- Does it preserve consistency?
- Does it strengthen hierarchy?

If not, reuse an existing structural pattern.

The Calinium Grid System values order, rhythm, flexibility, and timeless composition over experimental layouts.

A great grid is one users never consciously notice—but always benefit from.
