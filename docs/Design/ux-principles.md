# Calinium UX Principles

## Purpose

Calinium is built on established principles from cognitive psychology,
human-computer interaction, and user experience research.

These principles guide every interface decision.

Features are not added because they look attractive.

Components are not created because competitors have them.

Every interaction should reduce cognitive effort, increase confidence,
and help customers complete their goals.

---

# Fitts's Law

"The time required to reach a target depends on its size and distance."

Application:

- Primary buttons should be large enough to tap comfortably.
- Important actions should be easy to reach.
- Mobile controls should prioritize thumb reach.
- Touch targets should never be smaller than accessibility recommendations.
- Frequently used actions should require the least effort.

---

# Hick's Law

"The more choices users have, the longer they take to decide."

Application:

- Reduce unnecessary options.
- Prefer progressive disclosure.
- Avoid overwhelming navigation.
- Keep forms simple.
- Show only information that supports the current decision.

---

# Miller's Law

"The average person can hold only a limited number of items in working memory."

Application:

- Break complex interfaces into smaller sections.
- Group related information.
- Avoid long lists of equal importance.
- Use hierarchy instead of quantity.
- Keep Theme Editor settings organized into logical categories.

---

# Jakob's Law

"Users spend most of their time using other websites."

Application:

- Respect established Shopify patterns.
- Do not reinvent familiar interactions.
- Keep navigation predictable.
- Preserve expected ecommerce behaviors.

---

# Law of Prägnanz

"People perceive the simplest possible interpretation."

Application:

- Prefer clean layouts.
- Reduce visual noise.
- Remove decorative elements.
- Use strong alignment.
- Simplify compositions.

---

# Aesthetic-Usability Effect

"Users perceive attractive products as easier to use."

Application:

- Invest in typography.
- Maintain spacing consistency.
- Use harmonious proportions.
- Never sacrifice usability for aesthetics.

---

# Tesler's Law

"Every system has inherent complexity."

Application:

- Hide technical complexity from merchants.
- Provide intelligent defaults.
- Reduce unnecessary configuration.
- Let AI simplify decisions.

---

# Doherty Threshold

"Immediate feedback improves productivity."

Application:

- Fast loading.
- Responsive controls.
- Loading indicators.
- Optimistic updates only when safe.

---

# Peak-End Rule

"People judge experiences largely by their peak and ending."

Application:

Focus particularly on:

- Homepage first impression.
- Product page.
- Cart.
- Checkout transition.
- Thank-you experience (where applicable).

---

# Serial Position Effect

"People remember the first and last items best."

Application:

Homepage structure should prioritize:

1. Strong hero.
2. High-value content.
3. Trust builders.
4. Strong ending.

---

# Gestalt Principles

Apply:

- Proximity
- Similarity
- Continuity
- Closure
- Common Region
- Figure/Ground

Grouping should always reduce cognitive effort.

---

# Progressive Disclosure

Reveal complexity only when needed.

Never expose advanced controls before basic decisions.

---

# Recognition Over Recall

Interfaces should minimize memory requirements.

Users should recognize available actions rather than remember them.

---

# Cognitive Load

Every screen should minimize:

- unnecessary reading
- unnecessary choices
- unnecessary motion
- unnecessary decoration
- unnecessary decisions

---

# Decision Framework

Every new component should answer:

1. Which UX principle does it support?
2. Which UX principle could it violate?
3. Does it reduce or increase cognitive load?
4. Can it be simplified?
5. Does it help customers purchase with greater confidence?

If these questions cannot be answered clearly,
the component should be reconsidered.
