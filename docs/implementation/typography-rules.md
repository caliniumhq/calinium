# Typography Implementation Rules

## Purpose

The Typography Implementation Rules define how typography is implemented throughout every Calinium storefront.

These rules transform the Typography System into consistent, repeatable implementation decisions.

Typography should establish hierarchy, improve readability, support accessibility, and guide customer attention without becoming the focus of the interface.

Products communicate value.

Typography communicates understanding.

---

# Relationship to the Design System

These rules implement the principles defined in:

- Typography System
- Spacing System
- Grid System
- Accessibility System

Typography implementation must never contradict the Design System.

---

# Core Principles

## Hierarchy Before Style

Typography exists to organize information.

Visual hierarchy should always be stronger than stylistic variation.

Customers should immediately recognize what is:

- Primary
- Secondary
- Supporting

without conscious effort.

---

## Readability First

Readability always takes priority over visual expression.

Typography should remain comfortable across all supported devices and viewport sizes.

Decorative styling should never reduce comprehension.

---

## Consistency

The same content should always use the same typography role.

Typography should communicate meaning through repetition.

Avoid assigning different styles to identical content types.

---

## Restraint

Typography should support the product.

Avoid excessive variation in:

- size
- weight
- emphasis
- capitalization
- decoration

A calm hierarchy creates confidence.

---

## Accessibility

Typography should remain readable regardless of:

- screen size
- zoom level
- input method
- viewing conditions

Typography should never become a usability barrier.

---

# Typography Hierarchy Rules

Each typography role has a single responsibility.

Examples include:

- Display
- Heading 1
- Heading 2
- Heading 3
- Heading 4
- Heading 5
- Heading 6
- Body
- Caption
- Label
- Price
- Button

Roles should never be interchanged for stylistic purposes.

Meaning determines the role.

---

# Heading Rules

Only one H1 should appear on each page.

Headings must follow a logical hierarchy.

Heading levels should not be skipped.

Each heading introduces the content immediately following it.

Headings should describe structure rather than provide decoration.

---

# Product Rules

Product titles always use the Product Title typography role.

Prices always use the Price role.

Compare-at prices should remain visually secondary.

Product descriptions use Body typography.

Specifications use Label and Body roles.

Typography should reinforce purchase confidence.

---

# Button Rules

Buttons always use the Button typography role.

Button labels should remain concise.

Avoid excessive capitalization.

Typography inside buttons should prioritize clarity over expression.

---

# Form Rules

Every form control requires an associated label.

Labels should remain consistently styled throughout the storefront.

Helper text should remain visually secondary.

Validation messages should clearly communicate the problem and the recovery path.

---

# Navigation Rules

Primary navigation should receive greater emphasis than secondary navigation.

Navigation typography should remain concise and highly readable.

Navigation should never rely on decorative typography.

---

# Editorial Rules

Editorial content may introduce greater typographic expression while preserving readability.

Display typography should be reserved for moments of intentional emphasis.

Long-form reading should prioritize comfortable scanning over dramatic presentation.

---

# Alignment Rules

Typography should align consistently with the Grid System.

Avoid arbitrary text alignment.

Choose alignment based on content rather than visual preference.

Consistency improves scanning and comprehension.

---

# Line Length Rules

Body content should remain within comfortable reading widths.

Very long lines reduce readability.

Very short lines interrupt reading rhythm.

Layouts should preserve balanced line lengths across screen sizes.

---

# Emphasis Rules

Use emphasis sparingly.

Primary methods of emphasis include:

- hierarchy
- spacing
- position
- weight

Avoid relying on:

- multiple colors
- excessive bold text
- underlining
- decorative effects

Emphasis should direct attention without creating noise.

---

# Responsive Rules

Typography should adapt naturally across devices.

The hierarchy must remain consistent at every breakpoint.

Text should reflow without truncating meaningful content whenever possible.

Typography should remain readable at browser zoom levels supported by accessibility standards.

---

# Accessibility Requirements

Typography must support:

- Logical heading hierarchy
- Sufficient color contrast
- Browser zoom
- Responsive scaling
- Screen reader compatibility
- Readable line spacing
- Readable paragraph spacing

Typography should remain understandable without requiring perfect vision.

---

# Merchant Considerations

Merchants customize typography through structured settings such as:

- Typeface selection
- Scale
- Display style
- Density
- Brand personality

Merchants should not manually redefine typography roles.

The system preserves hierarchy automatically.

---

# AI Guidelines

When generating storefronts, AI should:

- Preserve semantic heading hierarchy.
- Reuse existing typography roles.
- Avoid unnecessary style variation.
- Prioritize readability.
- Match typography to the selected preset.
- Keep product information visually dominant.

Typography should explain the interface—not compete with it.

---

# Quality Checklist

Before approving typography implementation, verify:

## Hierarchy

- One H1 per page
- Logical heading order
- Clear content structure

## Readability

- Comfortable line lengths
- Balanced spacing
- Consistent alignment
- Clear emphasis

## Accessibility

- Semantic headings
- Adequate contrast
- Responsive scaling
- Zoom compatibility

## Consistency

- Correct typography roles
- No unnecessary variations
- Predictable styling

## Commerce

- Product titles are prominent
- Prices are immediately recognizable
- Purchase actions remain clear

---

# Future Compatibility

Before introducing a new typography rule, ask:

- Does an existing typography role already solve this problem?
- Does the rule improve readability?
- Does it strengthen hierarchy?
- Does it preserve accessibility?
- Will it remain appropriate across future presets?

If an existing rule already satisfies the requirement, reuse it.

The Typography Implementation Rules prioritize clarity, hierarchy, accessibility, consistency, and product-focused communication.

Typography should quietly organize information, allowing products and content to remain the center of attention.
