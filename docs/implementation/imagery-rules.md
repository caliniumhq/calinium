# Imagery Implementation Rules

## Purpose

The Imagery Implementation Rules define how images, videos, illustrations, and other visual media are presented throughout every Calinium storefront.

These rules transform the Imagery System into consistent implementation decisions that improve product presentation, reinforce brand identity, reduce cognitive load, and increase purchasing confidence.

Imagery is the primary storytelling medium of a storefront.

The interface exists to support imagery—not compete with it.

---

# Relationship to the Design System

These rules implement the principles defined in:

- Imagery System
- Layout System
- Grid System
- Motion System
- Accessibility System

If imagery implementation conflicts with the Design System, the Design System takes precedence.

---

# Core Principles

## Product Before Interface

Product imagery should remain the dominant visual element throughout the storefront.

Interface elements should quietly support product presentation.

No decorative element should compete with the product.

---

## Authentic Representation

Images should accurately represent the product.

Presentation should never exaggerate:

- color
- texture
- material
- finish
- scale

Customers should receive exactly what they expect.

---

## Consistency

Visual assets should feel like they belong to one coherent brand.

Consistency should be maintained across:

- composition
- lighting
- cropping
- perspective
- backgrounds
- aspect ratios
- color treatment

---

## Clarity

Every image should communicate one primary idea.

Avoid unnecessary visual distractions.

Customers should immediately understand what deserves attention.

---

## Performance

Imagery should remain visually rich while loading efficiently.

Visual quality should never require sacrificing storefront performance.

---

# Image Hierarchy Rules

Images should follow a predictable hierarchy.

Priority:

1. Product imagery
2. Lifestyle imagery
3. Detail imagery
4. Brand storytelling
5. Decorative graphics

Supporting visuals should never overshadow products.

---

# Product Image Rules

Product imagery should:

- accurately represent the product
- remain sharp
- preserve proportions
- maintain consistent framing
- avoid distracting backgrounds

Product images should never appear distorted or misleading.

---

# Gallery Rules

Product galleries should:

- maintain consistent image ratios
- preserve image quality
- support intuitive navigation
- prioritize the primary image

Changing gallery images should never disrupt page layout.

---

# Thumbnail Rules

Thumbnails should:

- accurately preview the selected media
- remain visually consistent
- clearly communicate the active state

Thumbnails should assist navigation rather than compete with the primary image.

---

# Lifestyle Image Rules

Lifestyle imagery should demonstrate:

- context
- scale
- real-world use
- emotional connection

Lifestyle images should support product understanding rather than replace product photography.

---

# Detail Image Rules

Detail imagery should highlight:

- craftsmanship
- materials
- texture
- construction
- finishing

Detail images should reinforce trust and perceived quality.

---

# Editorial Image Rules

Editorial imagery should support storytelling.

Editorial content should remain secondary to commerce.

Storytelling should strengthen purchase confidence rather than distract from shopping.

---

# Background Rules

Backgrounds should support product visibility.

Preferred characteristics include:

- minimal distraction
- consistent lighting
- appropriate contrast
- brand consistency

Backgrounds should never become the primary visual subject.

---

# Cropping Rules

Images should preserve:

- product proportions
- important visual details
- composition

Critical product features should never be unintentionally cropped.

Cropping should remain consistent across similar content.

---

# Aspect Ratio Rules

Similar content should use consistent aspect ratios.

Changing image proportions should not create visual instability.

Layouts should preserve rhythm regardless of media dimensions.

---

# Video Rules

Video should communicate:

- product function
- movement
- craftsmanship
- experience

Videos should support shopping rather than interrupt it.

Autoplay should be reserved for situations where it improves understanding and must respect browser and user preferences.

---

# Lazy Loading Rules

Media should load progressively.

Priority should be given to imagery immediately visible within the customer's viewport.

Deferred loading should improve performance without delaying meaningful content.

---

# Placeholder Rules

While media loads, placeholders should:

- preserve layout stability
- indicate incoming content
- minimize layout shifts

Loading placeholders should feel calm and unobtrusive.

---

# Responsive Rules

Imagery should adapt naturally across devices.

Responsive behavior should preserve:

- composition
- clarity
- hierarchy
- product visibility

Images should never become unreadable or excessively cropped on smaller screens.

---

# Accessibility Requirements

Every visual asset must support accessibility.

Requirements include:

- meaningful alternative text for informative images
- decorative images excluded from assistive technologies
- readable text overlays
- keyboard-accessible media controls
- captions where appropriate
- sufficient contrast

Visual information should never become inaccessible because of presentation.

---

# Merchant Considerations

Merchants should customize imagery through structured controls such as:

- image selection
- image order
- cropping preference
- aspect ratio
- media layout
- video enablement

Merchants should not manually control presentation logic.

The system should preserve visual consistency automatically.

---

# AI Guidelines

When generating storefronts, AI should:

- prioritize product imagery
- preserve realistic presentation
- maintain visual consistency
- avoid excessive cropping
- respect image hierarchy
- optimize layouts around media
- support brand identity without overwhelming products

The product should remain the strongest visual element on every page.

---

# Quality Checklist

Before approving imagery implementation, verify:

## Presentation

- Products remain visually dominant.
- Images are accurately represented.
- Composition is consistent.

## Hierarchy

- Product imagery has highest priority.
- Supporting imagery reinforces understanding.
- Decorative media remains minimal.

## Performance

- Responsive images are used.
- Lazy loading is implemented where appropriate.
- Layout shifts are minimized.

## Accessibility

- Alternative text is meaningful.
- Media controls are accessible.
- Text overlays remain readable.

## Commerce

- Images increase purchase confidence.
- Product details remain visible.
- Gallery navigation is intuitive.

---

# Future Compatibility

Before introducing a new imagery behavior, ask:

- Does it improve product understanding?
- Does it strengthen trust?
- Does it preserve visual consistency?
- Does it improve performance?
- Does it remain accessible?
- Does it support commerce?

If not, reuse an existing imagery pattern.

The Imagery Implementation Rules prioritize authenticity, consistency, accessibility, performance, and product-first presentation.

Every visual asset should help customers understand, trust, and confidently purchase the merchant's products.
