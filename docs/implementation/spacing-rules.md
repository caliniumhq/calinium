# Spacing Implementation Rules

## Purpose

The Spacing Implementation Rules define how spacing is applied throughout every Calinium storefront.

These rules transform the Spacing System into consistent implementation decisions that create visual hierarchy, improve readability, support accessibility, and reduce cognitive load.

Spacing is not empty space.

It is an intentional design tool that organizes information and guides customer attention.

Every spacing decision should reinforce clarity rather than decoration.

---

# Relationship to the Design System

These rules implement the principles defined in:

- Spacing System
- Grid System
- Typography System
- Layout System
- Accessibility System

If spacing behavior conflicts with the Design System, the Design System takes precedence.

---

# Core Principles

## Hierarchy Through Space

Spacing is the primary method of establishing hierarchy.

The distance between elements should communicate their relationship before borders, colors, or shadows.

Customers should immediately recognize which content belongs together.

---

## Consistency

Identical interface patterns should use identical spacing.

Customers should experience the same rhythm throughout the storefront.

Avoid arbitrary spacing adjustments.

---

## Rhythm

Spacing creates visual rhythm.

Pages should feel balanced from top to bottom.

Consistent rhythm makes interfaces easier to scan and understand.

---

## Separation

Spacing should clearly distinguish unrelated content.

Related elements remain visually grouped.

Unrelated elements receive greater separation.

Whitespace communicates structure.

---

## Restraint

More spacing is not always better.

Spacing should improve clarity without making interfaces feel disconnected.

Generous spacing should support content—not waste screen space.

---

# Spacing Hierarchy

Spacing should follow a predictable hierarchy.

```
Internal Element Spacing

↓

Component Spacing

↓

Section Spacing

↓

Page Spacing
```

Each level should remain visually distinct.

---

# Internal Component Rules

Spacing inside components should remain consistent.

Examples include:

- Button padding
- Card padding
- Form spacing
- Menu spacing
- Product information spacing

Internal spacing should support readability and interaction.

---

# Component Separation Rules

Separate independent components with more space than their internal elements.

Examples:

- Card to card
- Form to form
- Product card to product card
- Content block to content block

Customers should immediately recognize component boundaries.

---

# Section Rules

Sections should have clearly defined vertical spacing.

Each section should feel visually independent while remaining connected to the page flow.

Avoid sections appearing compressed or disconnected.

---

# Page Rules

Pages should maintain consistent outer spacing.

Content should never feel attached to the browser edges.

Margins should preserve comfortable reading and browsing experiences across all devices.

---

# Typography Spacing Rules

Typography spacing should reinforce hierarchy.

Examples include:

- Heading to paragraph
- Paragraph to paragraph
- List spacing
- Caption spacing

Spacing should improve reading flow without requiring decorative separators.

---

# Form Rules

Forms should use spacing to communicate relationships.

Labels remain visually connected to their corresponding inputs.

Related fields remain grouped.

Separate unrelated groups with additional spacing.

Spacing should reduce form complexity.

---

# Product Rules

Product information should use spacing to guide purchase decisions.

Examples:

- Image to title
- Title to price
- Price to purchase actions
- Purchase actions to supporting information

Primary purchasing information should remain visually connected.

---

# Navigation Rules

Navigation spacing should support scanning.

Navigation items should be easy to distinguish without feeling isolated.

Dropdowns and mega menus should preserve consistent spacing throughout.

---

# Responsive Rules

Spacing should adapt across viewport sizes.

Layouts may become more compact on smaller screens while preserving hierarchy.

Spacing reductions should never compromise readability or touch usability.

Every breakpoint should maintain visual rhythm.

---

# Accessibility Requirements

Spacing must support accessibility by providing:

- Comfortable touch targets
- Readable paragraph separation
- Clear grouping of related information
- Adequate focus visibility
- Reduced visual clutter

Spacing should improve comprehension rather than merely create visual balance.

---

# Merchant Considerations

Merchants should customize spacing through high-level controls such as:

- Layout density
- Section spacing
- Content width
- Preset selection

Merchants should not manually define spacing between individual interface elements.

The system should preserve spacing consistency automatically.

---

# AI Guidelines

When generating storefronts, AI should:

- Preserve spacing hierarchy.
- Keep related content grouped.
- Separate unrelated content clearly.
- Maintain consistent rhythm.
- Avoid arbitrary spacing adjustments.
- Match spacing density to the selected preset.

Whitespace should improve comprehension—not simply fill empty areas.

---

# Quality Checklist

Before approving spacing implementation, verify:

## Hierarchy

- Related content is grouped.
- Unrelated content is clearly separated.
- Visual rhythm is consistent.

## Readability

- Typography spacing supports scanning.
- Components feel balanced.
- Sections remain distinct.

## Accessibility

- Touch targets remain comfortable.
- Content is not visually crowded.
- Focus indicators remain visible.

## Consistency

- Spacing patterns are reused.
- Components share identical spacing behavior.
- No arbitrary spacing values appear.

## Commerce

- Product information flows naturally.
- Purchase actions remain visually prominent.
- Whitespace supports product imagery.

---

# Future Compatibility

Before introducing a new spacing rule, ask:

- Can an existing spacing pattern solve this problem?
- Does the new rule improve clarity?
- Does it preserve visual rhythm?
- Does it reduce cognitive load?
- Does it remain consistent with the Design System?

If an existing rule already satisfies the requirement, reuse it.

The Spacing Implementation Rules prioritize hierarchy, rhythm, consistency, readability, accessibility, and product-focused presentation.

Spacing should quietly organize the interface, allowing products and content to remain the center of attention.
