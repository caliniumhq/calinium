# Inspiration and Competitors

Inspiration and competitor records are distinct `reference_list` questions in the Brand References category. Each record can hold a name, optional URL, reason, admired traits, optional specific focus, optional screenshot asset, and optional market relationship.

The interface stores inspiration as research context only. It does not scrape referenced websites, copy layout, copy text, or treat a competitor as an instruction. Screenshot assets are project scoped and are uploaded through the same protected Asset Library boundary.
