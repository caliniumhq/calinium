# Merchant Profile Presentation

The default project profile view is a merchant-readable summary organized by business, existing presence, outcomes, brand direction, colors, typography, assets, inspiration, and competitors. It links back to the interview for edits and to the Asset Library for file management.

Raw JSON is deliberately secondary in a developer-only disclosure. A confirmed profile retains the core version-1 compiler-compatible fields and may include the optional `enrichment` extension. Every enriched value originates from an interview answer, a tenant-validated asset, or an explicit merchant approval; `enrichment.traceability` records that source.
