# Featured categories

## Purpose

An editorial category-navigation composition for collection, page, or custom destinations. It is intentionally not a generic collection grid.

## Settings and block API

Choose heading content, responsive columns, overlay or below-image layout, featured first item, media ratio, color scheme, and spacing. Each `category` block accepts a collection, page, or custom link; custom image; canonical icon; custom title; and short text. Link precedence is custom link, collection, then page.

## Accessibility, performance, and empty state

Each category has one semantic link with responsive, lazy media; decorative icons use the canonical renderer. The editor provides a simple placeholder for unconfigured categories. There is no JavaScript and no product data or cart behavior.

## Dependencies and limitation

Uses responsive image, icon, section heading, spacing, and Calinium color tokens. Product counts and product cards are deliberately outside this navigational section.
