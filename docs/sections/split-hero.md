# Split hero

**Purpose:** pair a strong image or Shopify-hosted video with a readable content panel.

**Settings:** image/mobile image or hosted video, media side, 40/60–60/40 desktop ratios, media ratio, heading/text/actions, color scheme, vertical alignment, and optional full-screen height.

**Block API:** none.

**Use:** launches, editorial explanations, and collection narratives where image and copy deserve equal attention.

**Accessibility and performance:** hosted video is muted and uses native controls. On mobile the panels stack without reordered keyboard controls. Images use `responsive-image`; headings, rich text, buttons, and spacing use canonical primitives. There is no autoplay in this section.

**Limitation:** external video embeds are intentionally excluded; use Video hero when a safe facade is required.
