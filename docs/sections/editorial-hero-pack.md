# Editorial & Hero Pack

This additive pack provides ten storytelling sections for Calinium One without changing templates, existing sections, or merchant settings. Each section uses Calinium’s canonical `section-heading`, `rich-text`, `button`, `responsive-image`, `icon`, and `section-spacing` primitives where applicable.

| Section | Best use |
| --- | --- |
| [Editorial hero](editorial-hero.md) | Typography-led campaign introduction |
| [Split hero](split-hero.md) | Balanced media and narrative |
| [Premium hero](premium-hero.md) | Canonical multi-mode, resource-safe homepage hero |
| [Full-screen hero](full-screen-hero.md) | Compatibility documentation for the stable `full-screen-hero` ID; see Premium Hero for current behavior |
| [Video hero](video-hero.md) | Cinematic motion with a poster fallback |
| [Lookbook](lookbook.md) | Fashion or lifestyle sequence |
| [Image mosaic](image-mosaic.md) | Curated asymmetric image composition |
| [Story banner](story-banner.md) | Contained brand narrative |
| [Editorial grid](editorial-grid.md) | Magazine-style destinations |
| [Quote banner](quote-banner.md) | Focused statement or quotation |
| [Brand manifesto](brand-manifesto.md) | Values and principles |

The sections are available through **Customize → Add section**. They are deliberately not inserted into any template. All images use Shopify-hosted responsive sources; below-the-fold images are lazy-loaded. The only interactive behavior is the existing Calinium video lifecycle, extended for pause/resume controls, visibility, and reduced-motion handling.
