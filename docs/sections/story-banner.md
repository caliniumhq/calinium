# Story banner

**Purpose:** a horizontal narrative pairing media, copy, an optional quote, and one action.

**Settings:** image/mobile image or hosted video, media ratio and side, eyebrow, heading, rich text, quote, action, full-bleed mode, border, color scheme, and spacing.

**Block API:** none.

**Use:** origin stories, process notes, and a contextual bridge between editorial content.

**Accessibility and performance:** video is muted with native controls; no autoplay is added. The media and narrative are ordered logically on small screens. Image rendering, heading, rich text, button, and spacing reuse canonical primitives.

**Limitation:** the optional quote is supporting copy only; use Quote banner for a full statement treatment.
