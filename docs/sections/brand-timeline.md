# Brand Timeline

**Purpose and use:** Presents two to twelve verified milestones in chronological order on an About page or as a mid-page journey.

**Settings and blocks:** Heading group, vertical or horizontal layout, ratio, and color/spacing controls. Each `timeline_item` provides date, title, description, optional image, and icon.

**Assets and safety:** Dates, places, launches, milestones, and achievements require merchant confirmation. AI may order supplied facts but cannot fabricate them.

**Accessibility and performance:** Uses an ordered list and semantic items. Horizontal mode progressively enhances native scrolling with keyboard-accessible controls and editor block reveal; vertical mode is fully server-rendered.

**Composition and limitation:** Use one Timeline per template, usually after Founder Story and before Craftsmanship or Values. Dependencies: `timeline-item`, responsive image, icon, shared carousel lifecycle.
