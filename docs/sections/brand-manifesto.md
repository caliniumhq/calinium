# Brand manifesto

**Purpose:** a typography-first values or philosophy section with optional supporting media.

**Settings:** eyebrow, heading, rich text, optional image/mobile image, action, minimal/split layout, media ratio, principle numbers, color scheme, spacing, and animation.

**Block API:** 2–6 `principle` blocks with heading and text.

**Use:** about pages, values sections, and premium positioning statements across industries.

**Accessibility and performance:** principles remain readable native content, with no JS dependency. The optional media is responsive and lazy-loaded; visual animation is disabled by reduced-motion preferences. The section composes `section-heading`, `rich-text`, `button`, `responsive-image`, and `section-spacing`.

**Limitation:** principles do not support individual links or icons; this keeps the manifesto intentionally restrained.
