# Full-screen hero

`full-screen-hero` is the stable section ID for the canonical **Premium Hero**.
It retains its established setting IDs so existing templates, generated snapshots,
and Theme Editor content continue to work. New work should use the Premium Hero
model rather than create another hero section family.

See [Premium Hero](premium-hero.md) for the canonical architecture, modes,
setting contract, generator mapping, lifecycle handling, and manual QA matrix.

Legacy specialist hero sections remain available only for historical templates
and deliberately specialised compositions; they are not the homepage bootstrap
target.
