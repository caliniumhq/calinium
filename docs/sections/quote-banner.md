# Quote banner

**Purpose:** give one quotation, testimonial-style statement, or brand assertion generous typographic space.

**Settings:** quote, attribution, role/source, optional image, optional decorative icon, alignment, narrow/wide width, quotation mark, color scheme, spacing, and restrained animation.

**Block API:** none.

**Use:** founder statements, press quotations, and brand positioning.

**Accessibility and performance:** semantic `blockquote` and `cite` markup are used. The optional icon and quotation mark are decorative. The optional image uses the canonical responsive-image primitive and does not create a duplicate textual announcement. No JavaScript is required.

**Limitation:** rating and carousel behavior are intentionally outside this editorial section.
