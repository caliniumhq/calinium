# Brand Storytelling Pack

This additive pack introduces ten distinct brand-storytelling sections and Calinium's first AI knowledge layer. It does not alter templates, existing instances, homepage composition, or merchant settings.

Every section has four maintained layers: Liquid, localized Theme Editor schema, a human guide, and a canonical manifest entry in `config/calinium-section-manifest.json`.

| Section | Primary purpose | Verification posture |
| --- | --- | --- |
| Founder Story | Founder and origin context | Merchant confirmation required |
| Brand Timeline | Dated history | Merchant confirmation required |
| Materials | Material education | Merchant confirmation required |
| Craftsmanship | Verified craft/process context | Merchant confirmation required |
| Manufacturing Process | Workflow explanation | Merchant confirmation required |
| Sustainability | Verified initiatives and evidence | Merchant only |
| Brand Values | Principles and philosophy | Context plus merchant confirmation |
| Team | Real people | Merchant only |
| Awards & Certifications | Verified recognition | Merchant only |
| Behind the Scenes | Real media gallery | Merchant only |

See [AI documentation](../ai/README.md) and the individual section guides for detailed configuration and composition rules.
