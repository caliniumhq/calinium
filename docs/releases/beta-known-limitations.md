# Calinium Beta Known Limitations

These boundaries apply to the first controlled beta unless a later release record explicitly supersedes them.

- Calinium One 1.0 is the only supported theme target.
- Generation produces a read-only downloadable theme package. Calinium does not upload, publish, or activate themes.
- Automatic theme updates are not supported.
- Every generation or update requires an explicit paid merchant action.
- Shopify Page destination binding is deferred.
- Typed external-link authoring remains limited to the currently approved contract.
- Verified metric presentation and direct certification-link capabilities are limited.
- Team contact-link authoring remains limited.
- Dynamic Shopify recommendation and complementary-product endpoint behavior requires live-store validation; static fixtures validate only the supported fallback boundary.
- Recently Viewed behavior depends on browser-local state and requires browser QA.
- Theme Editor lifecycle, cart interactions, responsive visual composition, screen-reader announcements, and dynamic focus restoration require manual development-store QA.
- No compatibility claim is made beyond browsers, versions, viewports, and assistive technologies explicitly recorded in a release report.
- The current release candidate has not completed Chrome, Firefox, and Safari/WebKit storefront validation.
- The current release candidate has not completed actual 200%/400% browser zoom or full keyboard-only storefront validation.
- Storefront Lighthouse scores have not been captured; the recorded dashboard scores must not be represented as storefront performance.
- A universal Lighthouse Performance score of 95 or higher is aspirational, not guaranteed.
- Compatibility with every Shopify app, app block, market configuration, or third-party script is not guaranteed.
- Shopify Partner ownership/distribution and production Billing API eligibility are not yet proven by live evidence.
- The repository catalog currently exposes a development/test price; a production price decision and activation are required before merchant billing.
- The Brand Storytelling Pack backup comparison is stale and non-authoritative for this release candidate. It was not run or updated.
- The workspace has no Git metadata, so release validation cannot make repository-wide Git diff claims.

Merchants must provide and approve all factual content, resources, evidence, destinations, and commerce relationships. Calinium omits unsupported content rather than inventing it.
