# Calinium Private Beta Merchant Checklist

Use this checklist only after the release candidate's blocking gates are closed.

## Before onboarding

- Confirm the merchant understands that Calinium One 1.0 is the supported target.
- Confirm the merchant accepts read-only package delivery and manual Shopify installation.
- Confirm an explicit paid action is required for each generation or update.
- Confirm the store is a development/test store during validation or is otherwise authorized for the beta.
- Record the tested browser/version, market, locale, currency, theme apps, and storefront password/contact process.
- Explain that unsupported facts, claims, quotations, evidence, and product relationships are omitted.

## Merchant content and access

- Connect the correct Shopify shop and verify project/shop scope.
- Approve only the products, collections, articles, images, video, navigation, and facts Calinium may consume.
- Provide required hero and commerce resources.
- Review the recommended preset and any compatible alternative.
- Review every content plan, block order, destination, image, claim, and commerce relationship.
- Resolve validation warnings before approving content.
- Confirm the immutable preset, plan, resource-snapshot, and order revisions shown at purchase.

## Pre-delivery QA

- Install the package on a duplicate/unpublished theme in the intended shop.
- Run Theme Check and confirm no package-integrity errors.
- Review homepage, product, collection, cart page/drawer, search, account links, and required editorial pages.
- Test desktop and mobile images, missing optional media, long titles, translations, and RTL when applicable.
- Test variants, quantity controls, Add to Cart, cart updates/removal, discounts, and checkout handoff.
- Test keyboard navigation, focus visibility, overlays, drawers, filters, markers, carousels, and reduced motion.
- Test Theme Editor section/block add, remove, reorder, duplicate, select, load/unload, and live setting updates.
- Record screenshots and browser console errors for every blocking or high finding.

## Delivery and support

- Verify the downloaded ZIP checksum and its authorized recipient.
- Preserve the approved revision IDs and generated manifest with the order record.
- Confirm no upload or publishing action occurred.
- Provide manual installation instructions and the rollback path.
- Record any untested Shopify apps or live integrations as merchant-specific limitations.
- Do not invite the merchant to publish until billing/distribution, storefront QA, and merchant acceptance are complete.
